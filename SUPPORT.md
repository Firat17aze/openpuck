# Getting help

Try these in order:

1. **[User guide](docs/user-guide.md)**: how every screen and setting works.
2. **[Install guide](docs/install.md)**: backing up, installing, updating and
   going back to the original firmware.
3. **[Troubleshooting](docs/troubleshooting.md)**: fixes for common problems.
4. **[GitHub issues](https://github.com/wavemoran/openpuck/issues)**: for bugs
   and feature ideas. Pick the form that fits and fill in the questions.
   Search first; someone may have reported it already.

GitHub Discussions will be linked here once it is turned on.

Security problems are different: please follow [SECURITY.md](SECURITY.md)
and do not post them publicly.
