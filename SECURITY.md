# Security policy

## Reporting a vulnerability

Please report security problems **privately**. Do not open a public issue.

1. Go to the [Security tab](https://github.com/wavemoran/openpuck/security) of this repository.
2. Choose **Report a vulnerability** and fill in the form.

Include what you found, how to reproduce it, and which version you tested.
You will get a reply as soon as the maintainer can read it. Please give us a
reasonable time to fix the problem before you share it publicly.

## Supported versions

Only the latest release is supported. Please update to it before reporting.

## What counts

OpenPuck does not use Wi-Fi or Bluetooth, so the
most likely problems are about the install tool (`tools/flash.py`), saved data
being read back, or the build and release process. Report anything you think
could harm an owner or their device.
