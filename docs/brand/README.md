# OpenPuck logo

<p align="center"><img src="openpuck-device.svg" width="160" alt="OpenPuck mark on a round screen"></p>

**The mark is an open ring with a bead in its gap.** The ring is the puck, the
round screen, the "O" of OpenPuck and the 0 a game starts from; the gap is the
"open"; the bead is the one live value being counted.

It's built from two primitives, an arc and a circle, so the firmware draws it
natively with LVGL (`main/logo.c`) instead of storing a bitmap, and it stays
sharp at any size from a 16 px favicon to the full 240×240 screen.

## Files

| File | Use |
|---|---|
| `openpuck-lockup.svg` | Wordmark, for dark backgrounds (README header in dark mode) |
| `openpuck-lockup-light.svg` | Wordmark, for light backgrounds |
| `openpuck-mark.svg` | Mark alone, dark backgrounds |
| `openpuck-mark-light.svg` | Mark alone, light backgrounds |
| `openpuck-mark-mono.svg` | One color, follows `currentColor` (stickers, laser-etching, 1-bit) |
| `openpuck-avatar.svg` / `.png` | Square tile, 512 px: GitHub org/repo avatar, favicon |
| `openpuck-social.png` | 1280×640 GitHub social preview (Settings → General → Social preview) |
| `openpuck-device.svg` / `-240.png` | Reference for the device screen at 1:1 |

All SVGs are regenerated by `tools/gen_logo.py` (Python + fontTools); the
wordmark is converted to outlines, so no font is needed to display them.

## Colors

| Name | Hex | Use |
|---|---|---|
| Bone | `#F5F2EA` | Ring and wordmark on dark |
| Ember | `#FF5A36` | Bead only. The one accent; don't use it for the ring |
| Ink | `#0E1013` | Backgrounds; ring and wordmark on light (`#16181C`) |

All three survive RGB565 on the GC9A01 without visible shift.

## Geometry

Defined on the device's 240×240 grid, center (120, 120):

- Ring: center-line radius 80, stroke 32, round caps → outer diameter 192.
  Arc runs clockwise from 347° to 283° (0° = 3 o'clock).
- Gap centered at 315° (top right); caps 32° either side.
- Bead: radius 16, on the ring's center line at 315°.

Scaling: stroke = diameter / 6. Keep at least a quarter of the diameter clear
around the mark.

## Wordmark

"OpenPuck" in Atkinson Hyperlegible Next Bold, the same face as the life
totals on the device, with the mark standing in for the "O". Tracking −1 %.
Don't set the wordmark with a normal "O" next to the mark.

## On the device

```c
#include "logo.h"
lv_obj_center(logo_create(lv_screen_active(), 192));   // full-screen splash
```

Smaller sizes work too (e.g. 48 for a menu header). The returned object isn't
clickable, so it never swallows taps meant for the counter.

## Don'ts

- Don't close the gap, move the bead off the ring, or add a second accent.
- Don't put the mark on a busy background or a light gray where the ring
  loses contrast; use the light variants on white.
- Don't use the MetalFab Tokens or Life Puck names in the logo.
